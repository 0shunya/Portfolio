# Shlok Singh, portfolio

React and Vite, pre-rendered at build time so the page reads without JavaScript.

```bash
npm install
npm run dev      # local development
npm run build    # production build in dist/
npm run preview  # serve the build at http://localhost:4173/
```

Deploys on Vercel: framework preset Vite, build command `npm run build`, output directory `dist`.
