# Shlok Singh, portfolio

Live at https://0shunya.github.io/Portfolio/

React and Vite, pre-rendered at build time so the page reads without JavaScript. Every push to `main` builds and publishes to the `gh-pages` branch.

```bash
npm install
npm run dev      # local development
npm run build    # production build in dist/
npm run preview  # serve the build at http://localhost:4173/Portfolio/
```
